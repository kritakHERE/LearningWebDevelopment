Focus Task Tracker Briefing

Build a small interactive task tracker with task creation, completion, deletion, summary counts, and empty-state handling.

What This Demonstrates

  • Reading and validating input with value and trim().
  • Storing tasks in an array of objects.
  • Rendering tasks into the DOM with forEach().
  • Finding a selected task with findIndex().
  • Removing tasks with splice().
  • Updating total, completed, and remaining counts.
