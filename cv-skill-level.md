My current strongest area is building small interactive frontend features with plain JavaScript. I completed a counter project with increase, decrease, reset, visual state changes, and disabled-button logic. I also built a Focus Task Tracker mini project that includes adding tasks, completing tasks, deleting tasks, showing empty states, disabling invalid input, and displaying summary counts for total, completed, and remaining tasks.

My level is best described as a motivated junior learner with practical beginner frontend skills and a strong technical background. I already have exposure to programming fundamentals, data structures, SQL/database concepts, Java, object-oriented programming, operating systems, and computer architecture. This helps me understand JavaScript not just as syntax, but as logic used to build real user interfaces.
