# Day 1 Briefing - DOM Basics

## Goal

Practice the first layer of browser JavaScript: selecting existing HTML, creating new elements, changing their content, placing them on the page, and removing them.

## What This Demonstrates

- `document.getElementById()` for DOM selection.
- `document.createElement()` for creating new HTML nodes.
- `.textContent` for safe text updates.
- `.setAttribute()` for changing element attributes.
- `appendChild()` for placing an element inside another element.
- `.remove()` for deleting an element from the live page.
- A button click triggering JavaScript behavior.

## Files To Review

- `index.html` - minimal page structure and the button target.
- `style.css` - basic styling for the practice area and generated content.
- `script.js` - the main DOM creation and removal practice.

## How To Run

Open `index.html` in a browser, then click **Run Practice Code**.

## Definition Of Done

- An existing element is selected from the page.
- A new element is created with JavaScript.
- Text is inserted into the new element.
- The new element is appended into the practice area.
- An attribute/class is added.
- The generated element can be removed by button interaction.

## Recruiter Signal

This folder shows that I understand the DOM as a live page structure that JavaScript can read, create, modify, and remove.
